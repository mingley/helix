# Official final-paper joint-library source

`raw/jointdata.xlsx` is the unchanged Table 11 member of the final supplementary
archive for Agarwal et al., *Massively parallel characterization of
transcriptional regulatory elements*, Nature (2025),
DOI [10.1038/s41586-024-08430-9](https://doi.org/10.1038/s41586-024-08430-9).
The article distributes these supplementary tables under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

The workbook is 53,557,805 bytes, SHA-256
`9c95ca2b8df0ff3edc7dda4fdcf337f33e652b96a0833a70e786bbcdc2b76b4e`.
It contains published aggregate activities, individual replicate measurements,
replicate summaries and element specificity scores. Those endpoints are
distinct. Library-normalized log2(RNA/DNA) is not absolute expression per cell.

The complete official archive was acquired under the separately frozen
[recovery protocol](../../experiments/context-endpoint-recovery-v1.json),
before any values were inspected. Its 342,234,089 bytes have SHA-256
`aefb1974e9ebe5c196a89a00f4e868c0abaf69e3d3952e79c74bfb42f217f6a4`.
All 13 members passed independent bounds, size and CRC checks. The outer archive
remains in the tool cache and is not committed; only the selected new workbook
is retained here. Other library measurements were not interpreted.

Final Table 10 is byte-identical to the previously retained
[Zenodo S7 design workbook](../context-panel/raw/Table-S7-joint-design.xlsx).
Final Table 12 is byte-identical to the previously retained
[Zenodo S9 model workbook](../context-panel/raw/Table-S9-folds-performance.xlsx).
The alternative table numbers are release mappings, not independent experiments.

[Source receipts and binding](../../research/context-endpoint-recovery/source/)
retain exact member paths, hashes, acquisition metadata, the header-only gate,
numeric-cell/type/missingness ledgers and untouched source lexemes. The source
values are not recentered or rescaled to replace an earlier endpoint.
